# PRAKTIKUM PERTEMUAN 3 - LKP 2B
## Membuat Halaman Profil Responsif

### DESKRIPSI
Praktikum ini merupakan pengembangan dari LKP 2A, yaitu membuat halaman profil responsif menggunakan HTML dan CSS dengan menambahkan media queries agar tampilan dapat menyesuaikan berbagai ukuran layar.

### STRUKTUR FOLDER
- `index.html` : Halaman profil.
- `style.css` : File CSS dengan tambahan media queries.
- `assets/foto.jpg` : Gambar profil.
- `screenshot-375.png` : Tampilan ukuran layar 375px.
- `screenshot-768.png` : Tampilan ukuran layar 768px.
- `screenshot-1200.png` : Tampilan ukuran layar 1200px.

### CARA MENJALANKAN
1. Buka folder LPK-2B menggunakan Visual Studio Code.
2. Jalankan file `index.html` melalui browser atau Live Server.
3. Pastikan halaman profil dapat ditampilkan dengan baik.
4. Pastikan navigasi Tentang, Keahlian, dan Kontak berfungsi.

### PENGUJIAN RESPONSIVITAS
Pengujian dilakukan menggunakan Google Chrome dengan fitur Device Toolbar pada ukuran:
- 375px (iPhone SE): Cards tampil 1 kolom.
- 768px (iPad): Cards tampil 2 kolom.
- 1200px (Desktop): Cards tampil 4 kolom.

### KESIMPULAN
Melalui praktikum ini, halaman profil dari LKP 2A dikembangkan menjadi halaman web responsif dengan memanfaatkan media queries pada CSS sehingga tampilan dapat menyesuaikan ukuran layar perangkat.
