# Analisis Komparatif Platform Web, Desktop, dan Mobile
## Tabel Analisis Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, dan JavaScript untuk membuat tampilan serta fitur website | C#, Java, C++, atau Python sesuai aplikasi yang dibuat | Kotlin atau Java untuk Android, serta Swift untuk iOS |
| Arsitektur | Digunakan melalui browser dan dapat mengambil data dari server | Dipasang dan dijalankan langsung di komputer | Dipasang pada smartphone atau tablet |
| Cara distribusi | Dibagikan melalui link website | Dibagikan melalui file instalasi atau toko aplikasi | Dibagikan melalui Play Store atau App Store |
| Keunggulan | Mudah dibuka tanpa harus memasang aplikasi khusus | Cocok untuk pekerjaan yang membutuhkan fitur komputer | Praktis digunakan kapan saja melalui smartphone |
| Keterbatasan | Beberapa fitur membutuhkan koneksi internet dan dukungan browser | Perlu instalasi dan harus sesuai dengan sistem operasi | Ruang layar terbatas dan aplikasi perlu menyesuaikan jenis perangkat |
| Contoh aplikasi | Gmail, Google Docs | Visual Studio, Notepad | WhatsApp, Google Maps |

## Kesimpulan
Web, desktop, dan mobile memiliki kegunaan yang berbeda. Web lebih praktis karena bisa dibuka melalui browser, desktop cocok untuk pekerjaan di komputer, sedangkan mobile memudahkan pengguna mengakses aplikasi melalui smartphone. Karena itu, platform sebaiknya dipilih berdasarkan fungsi aplikasi dan kebutuhan penggunanya.
